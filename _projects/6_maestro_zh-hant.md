我參與研究並實作了一個雙流 Bidirectional LSTM（BiLSTM）架構，能即時將手部動作轉換成有意義的數位指令。此專案獲得 **國立東華大學專題優秀獎 2026**。

### 主要貢獻
- **深度學習架構：** 使用 Python 與深度學習框架訓練雙流 BiLSTM 模型，同時處理空間與時間資訊。
- **即時推論：** 優化推論流程，降低延遲，讓手勢預測可用於即時互動。
- **基礎架構與 DevOps：** 管理專案架構與 GitHub 組織，建立 CI/CD，自動化測試與部署。
- **模組化設計：** 讓 Python 程式碼具備可重現性與可擴充性，兼顧研究速度與維護性。

### 我學到的事
- 電腦視覺中的時序資料處理與序列建模。
- 協作式機器學習研究中的 CI/CD 重要性。
- 以 Python 設計可測試、可延伸的模組。
- 在研究速度與程式維護之間取得平衡。

**技術棧：** Python, 雙流 BiLSTM, 深度學習框架, GitHub Actions。
