Built a **high-performance real-time communication system** a concurrent C++/Qt backend combined with a responsive QML frontend, deployed across multiple platforms from a single shared codebase.

### Key Contributions
- Built high-performance real-time messaging system with voice notes, file sharing, groups, and typing indicators
- Engineered backend concurrency in C++/Qt and responsive frontend in QML
- Deployed to Android, iOS, macOS, Windows, and WebAssembly from a shared C++ core

### What I Learned
- Designing low-latency backend systems with practical concurrency models in C++ and Qt.
- Cross-platform architecture and UI adaptation across device classes from a single codebase.
- End-to-end product thinking from protocol design to device-specific UX.

**Tech Stack:** C++, Qt, QML, AWS, MongoDB. Targets: Android, iOS, macOS, Windows, WebAssembly.
