Built a **full-stack mobile task management app** with a C++ (Drogon) REST API backend and React Native (Expo) frontend helping students stay on top of coursework with real-time Moodle sync.

### Key Contributions
- Built a full-stack mobile task management app with a C++ (Drogon) REST API backend and React Native (Expo) frontend
- Integrated Moodle LMS API to automatically sync course assignments directly into the app
- Implemented offline-first architecture with SQLite, push notifications with reminders, and a calendar view
- Deployed on Android with JWT authentication and a self-hosted backend tunneled via Cloudflare

### What I Learned
- Translating real student pain points into concrete UX decisions.
- Backend architecture in C++ for performance-critical services; memory and performance tradeoffs.
- Build system discipline with CMake and environment setup automation.

**Tech Stack:** React Native (Expo), C++ (Drogon), SQLite, JWT, Cloudflare.
