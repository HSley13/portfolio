Collaborated on the research and implementation of a **two-stream Bidirectional LSTM (BiLSTM)** architecture that translates physical hand movements into meaningful digital commands in real time. Awarded the **NDHU Undergraduate Project Excellent Award 2026**.

### Key Contributions
- **Deep Learning Architecture:** Developed and trained the two-stream BiLSTM models in Python, processing both spatial and temporal data streams from hand motion for highly accurate gesture classification.
- **Real-Time Inference Pipeline:** Optimized the inference pipeline to minimize latency, enabling responsive real-time gesture prediction suitable for live control scenarios.
- **Infrastructure & DevOps:** Managed the project's infrastructure and GitHub repository structure; implemented **CI/CD pipelines** to automate testing and deployment, ensuring a reliable and reproducible build process across all contributors.
- **Modular Architecture:** Structured the Python codebase for fast iteration, reproducibility, and easier extension balancing research speed with maintainability.

### What I Learned
- Time-series data processing and sequence modeling in computer vision contexts.
- The importance of robust CI/CD practices in collaborative machine learning research.
- Designing modular, testable Python services and scripts for ML experimentation.
- Fast prototyping while keeping the codebase extensible for future research directions.

**Tech Stack:** Python, BiLSTM (two-stream), deep learning frameworks, CI/CD (GitHub Actions).
